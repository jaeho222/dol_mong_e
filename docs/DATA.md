# region_metrics.csv 스키마

Agent와 계산 도구가 보는 **유일한 데이터 테이블**. 행 = 비교 단위 지역(14곳), 열 = 지표.
실제 값은 Supabase `refined.region_metrics` view 가 계산하고, `python -m data.build.export_supabase` 가
`data/processed/region_metrics.csv` 로 내보낸다. 계산식 전체: `supabase/sql/20_region_metrics.sql`.
데이터 번호 ↔ 이름 매칭과 받지 않은 데이터의 사유: `docs/DATA_CATALOG.md`.

**권역 판별 방법**: 주소·읍면동 이름은 키워드 표(`refined.region_keyword`)로 14개 권역에 배정한다.
위경도만 있는 데이터는 가장 가까운 버스정류소(612, 4,352곳)의 주소로 권역을 정한다.
