# 비용 추정 모델

코드: `backend/tools/cost.py` (단가는 전부 `COST` 딕셔너리 한 곳에)

## 공식

```
총비용 = 숙소 + 이동 + 식비 + 공과금·난방

숙소(단기) = Σ(하루) [ base_stay_month × rent_index × 인원배율 / 30 × 그 날짜 월의 성수기배율 ]
            × 기간 할인배율 + 청소비
숙소(연세) = 연세기준 × rent_index × 인원배율 × 올림(일수/365) + 초기세팅비   ← 90일 이상이면 둘 다 계산해 싼 쪽
이동       = 렌터카 월단가(월별) 일할  |  차 없으면 버스 월 6만 × 인원
식비       = (1인 60 + 추가 1인당 50) × 개월
공과금     = 월 8(단기) / 15(연세) + 겨울(12~2월) 난방 가산 (중산간이면 추가)
표시 범위  = 총비용 × (1 ± 0.15)
```

## 현재 가정값과 근거

| 항목 | 값 | 근거 | 상태 |
|---|---|---|---|
| 권역 단기숙소 월가 | 제주시 115 / 서부 105 / 동부·서귀포 90 (만원, 1인) | jeju.com 2026 가이드: 제주시 80~150, 서귀포·동부 60~120 의 중간값 | 가정 |
| 성수기 배율 | 7·8월 1.30, 겨울 1.10, 11월 0.90 | 가이드 "성수기 20~30%↑" | 가정 |
| 기간 할인 | ~13일 1.25 / ~27일 1.10 / ~89일 1.0 / ~180일 0.88 / 그 이상 0.80 | 리브애니웨어 월 할인 22% 사례 | 가정 |
| 연세 기준 | 639 (보증금 247 별도) | 당근부동산 제주시 원룸 연세 평균(2026-11 스냅샷) | 표본 |
| 렌터카 | 비수기 40~50 / 7·8월 100 | 가이드 40~60, 성수기 SUV 100+, 경향신문 시즌 10배 | 가정 |
| 식비 | 1인 60 | 가이드 취사 위주 50~70 | 가정 |
| 겨울 난방 | +10, 중산간 +10 | 기름보일러 사례(서울 기준) — 제주 데이터 없음 | 가정 |
